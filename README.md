# 菜菜专属 · 课表日历

菜菜的专属课表转换小工具：把学校教务系统导出的 Excel 课表（`.xls` / `.xlsx` / `.csv`）转换成可以导入手机日历的 `.ics` 文件。纯前端、无后端，文件只在浏览器本地解析，不会上传到任何服务器。

> **在线使用**：<https://charlie077-cuso.github.io/caicai-calendar/>（手机浏览器直接打开，可添加到主屏幕 / 离线使用）

## 功能

- **四步向导**：上传课表 → 核对课程 → 校对上课时间 → 生成 `.ics`
- **自动解析**：识别星期表头、节次列、课程名、教师、地点、周次（含单双周、跳周、大节、日期表头等常见格式）
- **手动校正**：解析结果可逐门编辑、删除、手动添加；支持多工作表切换
- **时间校对（简化版）**：填学期第 1 周周一、上午/下午/晚上第 1 节开始，选一个作息模板（45/40/50 分钟一节、大节内节间 5/10 分钟、大节之间 10/20 分钟）即可自动推算所有时段；学校作息特殊可选「自定义」，需要时展开「高级」逐节微调
- **调课 / 停课**：导出前可添加停课日期（自动跳过当天课程）和补课事件，配置保存在浏览器本地
- **温暖陪伴**：页面顶部有一条夸夸文案，共 96 条，洗牌抽签、90 次内不重复，刷新后从上次进度继续
- **标准 ICS**：`VTIMEZONE` + `TZID`、每周重复（`RRULE` + `EXDATE`）、单双周/跳周、可选上课提醒、75 字节安全折行、稳定 UID
- **手机优先**：iPhone / Android 浏览器都能用；可「添加到主屏幕」当 App 用（PWA，离线可用）
- **隐私**：不上传文件、不依赖服务器、无账号、无统计

## 使用步骤

1. 在学校教务系统「我的课表」页面导出 Excel。
2. 打开本工具，选择或拖入课表文件。
3. 核对解析出的课程：点卡片可修改名称、教师、地点、星期、节次、周次。
4. 填写学期第 1 周周一（按校历的第 1 周，不是正式上课那天）、上午/下午/晚上第 1 节开始时间，确认时段预览。
5. 选好时区、提醒、重复方式；有调课就在「调课 / 停课」里加停课/补课；点「生成并下载 .ics」。
6. 在手机上打开下载的 `.ics`，选择「日历」导入。

### 导入说明

- **iPhone / iPad**：Safari 下载后会自动提示用「日历」打开；没有的话去「文件」App 点一下下载的文件。
- **Android 系统日历**：在通知栏或「文件管理 → 下载」中点开 `.ics`，选择系统日历导入。
- **Android + Google 日历**：Google 日历 App 没有导入按钮。用 Chrome 打开 [Google 日历导入页](https://calendar.google.com/calendar/u/0/r/settings/export)，勾选 Chrome 菜单里的「桌面版网站」，再「导入和导出 → 选择文件 → 导入」。
- **Google 日历（电脑）**：网页版 → 设置 → 导入和导出 → 选择 `.ics`（单文件需小于 1 MB）。

## 夸夸文案

页面顶部的小条会随机显示一条温柔的话，每次打开、上传成功、切换步骤、生成日历都会换一条。文案池共 96 条，采用洗牌抽签：**连续 90 次显示不重复**，96 条全部抽完才开启下一轮，且新一轮第一条不会和上一轮最后一条相同。抽签进度存在 `localStorage`（`caicai.warm.v1`），刷新页面不会回到开头。

自检：`node tools/test-warm.js`（检查 96 条无重复、刷新后继续、一轮内不重复、跨轮不重复）。

## 隐私

- 课表文件只在浏览器内存中解析，**不会**发送到网络。
- 设置（作息时间、时区、提醒、停课/补课）保存在浏览器 `localStorage`，清空浏览器数据即删除。
